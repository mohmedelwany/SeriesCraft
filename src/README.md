# Series Craft

Create ordered post series with a clean front-end table of contents and next/prev navigation to guide readers through multi-part articles.

## Description

Series Craft allows you to group posts into series, providing a structured way for readers to navigate through multi-part content.

## Features

- Table of Contents for post series.
- Next/Previous navigation buttons.
- Easy management of series from the WordPress admin.

## Installation

1. Upload the `series-craft` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
